1. WHAT THE SETTINGS PAGE DOES (TECHNICAL)
================================================================================

Page: Settings → ETA E-Receipt (Fratelanza ERP web admin)
URL:  https://erp.fratelanza.com/settings

When the pharmacy admin clicks "Test connection", our backend performs:

  POST {BaseUrl}/EtaDocument/Documents
  Content-Type: application/json
  Body: {"Documents":[]}

  Headers (API v2):
    EtaAuthentication: <auth key from credential.txt>
    EtaTimestamp:      <Unix seconds UTC>
    EtaSignature:      Base64(HMAC-SHA256(authKey + timestamp + rawJsonBody, secretKey))
    EtaAPIVersion:     2

HMAC payload string (no spaces):
  authKey + timestamp + '{"Documents":[]}'

Expected on success:
  HTTP 200 with JSON body; auth OK if no ERR_AUTH_* / ERR_HMAC_* / ERR_IP_DENY codes.
  Empty Documents[] may return validation errors — that is still auth success.

Credentials are stored encrypted in tenant PostgreSQL table: eta_credentials
Branch/POS mapping: eta_branch_devices (BranchCode B01, PosSerial P01)
